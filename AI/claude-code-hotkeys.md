Кастомизация горячих клавиш возможна через создание файлы keybindings.json, либо через команду /keybindings (откроет текущий глобальный keybindings.json).

1) Ctrl + C - прекращение текущих операций. При нажатии дважды - выход из текущей сессии.
2) Esc дважды - открытие rewind интерфейса для перемещения по чекпоинтам сессии. Можно откатиться к какому то моменту обсуждения разными способами (клод их предложит), например, восстановить только код, или только общение, или и то и другое.
3) Ctrl + R - поиск по итории промптов. Осуществляется по словам, которые были использованы при составлении промпта.
4) Ctrl + G - открыть редактирование во внешнем редакторе. Удобно если промпт получается большим. Рекдактор закрывается стандартным для него набором команд, и после этого весь промпт оказывается в командной строке.
5)  Ctrl + S - застешить промпт для использования позже. Может возникнуть ситуация, когда с написания одного промпта нужно переключиться на другой. Тогда чтобы не потерять наработки можно использовать комбинацию выше для временного хранения старого промпта. После отправки нового промпта, застешенная версия сразу появится в командной строке.
6) Shift + Tab - переключение режимов.
7) Ctrl + P - вызов выбора моделей (то же что команда /model).
8) Ctrl + B - скрыть текущую задачу, переключиться на другую. Скрывает лог выполнения запущенного промпта.
9) Ctrl + T - показать внутренний to-do лист задчи клода.
