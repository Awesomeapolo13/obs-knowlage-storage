## Общие сведения

**Скилл** — Claude сам решает, когда вызвать (явно через `/skill-name` или по описанию). Участие модели обязательно.

**Хук** — срабатывает **автоматически** при наступлении события, независимо от решения Claude. Это программный контроль над действиями агента.

Сценарии хуков


| Хук              | Момент срабатывания                    | Типичное использование                    |
| ---------------- | -------------------------------------- | ----------------------------------------- |
| **PostToolUse**  | После использования инструмента        | Форматирование файла после редактирования |
| **PreToolUse**   | До выполнения инструмента              | Блокировка опасных команд или файлов      |
| **Notification** | Когда Claude ждёт ввода пользователя   | Уведомление на рабочий стол               |
| **Stop**         | Когда Claude полностью завершил задачу | Уведомление об окончании работы           |

### Конфигурация в .claude/settings.json

```json
{
	"hooks": {
		"PostToolUse": [// КОгда будет использован
			{
				"matcher": "Edit|Write", // фильтр для каких инструментов
				"hooks": [
					{
						"type": "command", // тип хука
						"command": "npx prettier --write ..."  // что выполнить
					}
				]
			}
		]
	}
}
```

Так же можно добавить блок `"if": "Edit(*.ts)|Write(*.ts)"`, чтобы ограничить форматы файлов, для которых будет выполняться хук.

### Как хук общается с Claude

- **Код возврата 0** — хук выполнен успешно, Claude продолжает работу;
- **Код возврата 2** — хук заблокировал действие, Claude останавливается, можно сделать вывод в `stderr` передаётся Claude как объяснение причины блокировки;
- Любой другой код  - действие продолжается но в лог пишется ошибка.

### Пример блокировки DROP TABLE

```shell
#!/bin/bash
COMMAND=$(echo "$CLAUDE_TOOL_INPUT" | jq -r '.tool_input.command')
if echo "$COMMAND" | grep -qi "drop table"; then
	echo "Заблокировано: DROP TABLE запрещён в этом проекте" >&2
	exit 2
fi
exit 0
```

Это **надёжная защита** — в отличие от правил в CLAUDE.md, которые Claude может проигнорировать, хук работает на программном уровне и не зависит от поведения модели.

### Полный список событий

Помимо основных четырёх, доступны: `SessionStart`, `UsePromptSubmit`, `PreCompact`, `PostCompact`, `SubagentStop`, `ConfigChange`, `TaskCreate` и другие. На практике чаще всего используются `PreToolUse` и `PostToolUse`.
