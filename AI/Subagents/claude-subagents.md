## Общие сведения

Используются для реализации рабочих процессов заточенных под определенные задачи, а так же для улучшения управления контекстом.

Субагенты - специализированные ИИ ассистенты, которые обрабатывают специфические типы задач. Каждый субагент запускается в своём собственном контекстном окне с кастомным системным промптом, доступом к специальным инструментам и независимыми доступами. Как только Клод встречается с задачей подходящей под описание субагента, он делегирует ему работу и тот работает независимо, возвращая результаты в основной поток.

Субагенты позволяют:
- Сохранять контекст, выполняя исследования и реализации вне основного общения;
- Обеспечивает соблюдение ограничений, ограничивая инструменты, которые субагент может использовать;
- Повторно использовать конфигурацию через проекты с помощью субагентов уровня пользователя;
- Специализируйте поведение с помощью целенаправленных системных подсказок для конкретных доменов;
- Контролируйте расходы, перенаправляя задачи более быстрым и дешевым моделям, таким как Haiku.

Клод использует описание каждого субагента, чтобы решить, когда делегировать задачи. Создавая субагент, необходимо написать четкое описание, чтобы Клод знал, когда его использовать.
