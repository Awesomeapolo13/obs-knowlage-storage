
# Встроенные субагенты

**Ключи:**
- Обратные:
	- [Клод код](claude-code);
	- [Субагенты](claude-subagents).
- Прямые:

**Хештеги:**
- #AI/Claude/Subagents

Клод включает в себя встроенные субагенты, которые он автоматически использует для подходящих задач. Каждый из них наследует разрешения родительского диалога с дополнительными ограничениями инструментов.

Помимо этих встроенных субагентов, можно создавать свои собственные промпты, ограничения инструментов, режимы разрешений, перехватчики и навыки.

## Explore

Быстрый рид-онли агент оптимизированный для поиска и анализа кодовой базы.
- Модель - Haiku (быстрая, с низкой задержкой);
- Инструменты - Только для чтения (запрещен доступ к инструментам Записи и Редактирования);
- Назначение - Исследования файлов, пойск по коду, исследование кодовой базы.

Клод делигирует к Explore, когда нужно искать или понять кодовую базу без совершения измененый. Это позволяет исключить результаты из контекста главного диалога.
При вызове Explore Клод указывает уровень доскональности:
- быстрый - для целевого поиска;
- средний - для сбалансированного исследования;
- очень доскональный - для комплексного анализа.

## Plan

Агент исследования используется в режиме планирования, чтобы собирать контекст перед презентацией плана.
- Модель - наследует модель основного диалога.
- Инструменты - Только для чтения.
- Назначение - Исследование кодовой базы для планирования.

Когда активен режим планирования и Клоду необходимо понимать кодовую базу, он делегирует исследование субагенту Plan. Это предотвращает бесконечную вложенность (субагент не может вызвать другого субагента) пока идет сборка необходимого контекста. 

## General-purpose

Способный агент для комплексных, многоступенчатых задач, которые требуют обоих операций исследования и выполнения.
- Модель - наследуется из основного диалога.
- Инструменты - Все
- Назначение - Комплексный анализ, многоступенчатые операции, модификация кода.

Клод делегирует к general-purpose, когда задача требует и исследования и модификации, сложных рассуждений для интерпертирования результатов или множества зависимых друг от друга шагов.

## Другие

У клода есть и дополнительный агенты-помощники для специфичных задач. Они обично вызываются автоматически, поэтому нет необходимости использовать их прямыми вызовами.


| Агент             | Модель         | Когда Клод использует                                           |
| ----------------- | -------------- | --------------------------------------------------------------- |
| Bash              | Унаследованная | Запускает команды в терминале в отдельном контексте             |
| statusline-setup  | Sonnet         | Когда запускаем `/statusline`, чтобы настройку строки состояния |
| Claude Code Guide | Haiku          | Когда спрашиваем о навыках Клод Кода                            |
